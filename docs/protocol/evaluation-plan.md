# SHIFT — Evaluation Protocol (locked v1, 2026-11-17, before any SHIFT measurement)

Changes after this point are appended to the "Amendments" section with date and reason. Exploratory analyses are labeled as such in the paper.

## Units and data
- Dataset: SWE-bench Verified (500 instances, 12 repos), HF parquet snapshot in `data/external/`.
- Agent panel: every system in the public `bash-only` (mini-swe-agent) track with ≥ 450 patch files (RQ1). Trajectory sub-panel: one run per model family with trajectories (RQ1 exploration). Multiple runs of the same model are kept as separate systems but flagged; sensitivity analysis with one run per model.
- Execution subset (RQ2–RQ4): Django and SymPy instances whose environment validates: gold patch makes all FAIL_TO_PASS pass and keeps PASS_TO_PASS passing, and the base commit fails ≥ 1 FAIL_TO_PASS test. Exclusions are logged with reason.
- Agent patches for RQ2–RQ4: resolved patches (official report) from a fixed panel of 6 systems chosen *before* measurement to span capability and vendors (see `configs/study.yaml`), restricted to the validated execution subset; re-validated locally (a patch that does not reproduce resolution locally is excluded and counted).
- Experimental unit: a patch (system × instance). Edits are nested in patches, patches nested in instances. All intervals use instance-cluster bootstrap (10,000 resamples, percentile).

## RQ1 Footprint (confirmatory for H1/H2 directional differences; exploratory for associations)
- Measures per patch: files edited (source / test / auxiliary), hunks, change blocks, churn (added+removed lines), reference divergence (Jaccard distance on edited source files vs gold), nonlocal share (fraction of source change blocks in files not edited by gold), dispersion (mean pairwise undirected import-graph distance among edited source modules; disconnected pairs reported separately), auxiliary-file leftovers (new files not under the package or tests).
- Trajectory measures: distinct repository files inspected (read commands parsed from bash actions), steps, exploration-to-edit ratio EER = |inspected| / max(1, |edited|).
- Comparison: paired (instance) differences agent − gold; Wilcoxon signed-rank per system, Holm correction across systems within each metric; effect size = matched-pairs rank-biserial correlation. Association with resolution: per system, logistic GEE (resolved ~ log1p(churn) + nonlocal_share + n_files) clustered by instance, reported exploratory.
- Decision rule: H2 supported for a metric if ≥ 2/3 of systems show a Holm-significant difference in the same direction.

## RQ2 Necessity (primary estimand: proportion of change blocks labelled Unneeded among resolved agent patches)
- Labels from SHIFT counterfactual analysis (oracle = F2P ∧ P2P, 2 repeated runs for full patch to detect flakiness).
- Proxies predicting "needed" (N ∪ J): gold-file, issue-mention, import-proximity (≤1 hop of a gold file), all-needed, and five LLM judges (qwen2.5-coder:7b, phi4:14b, gpt-oss:20b, devstral:24b, qwen3-coder:30b; temperature 0.2; 3 seeds; majority vote reported, self-consistency reported).
- Metrics: precision/recall/F1 for the *Unneeded* class (flagging task) and MCC; nonlocal-needed retention = fraction of needed edits outside gold files that a proxy labels needed. Interval: instance-cluster bootstrap.
- Decision rule: H3 supported if location-based proxies have nonlocal-needed retention < 0.5 while SHIFT retains all by construction, and their Unneeded-class F1 is below the best LLM judge's or SHIFT's.

## RQ3 Preservation
- Real patches: envelope tests = dependency-selected test modules (tests importing edited modules, ≤ 8 modules, ≤ 15 min budget) beyond the official test files. Regression = test passing on base and on gold-patched program, failing on agent-patched program; flaky tests (inconsistent across 2 base runs) excluded. Report: fraction of resolved patches with ≥ 1 envelope regression invisible to P2P; attribution labels.
- Controlled injection: on validated gold patches, inject one change block into a nonlocal module in the import neighbourhood: (a) semantic mutation (relational-operator flip, boolean-negation, constant perturbation, return-value replacement), (b) semantics-preserving edit (comment/docstring, local-variable rename, redundant parentheses). Seeds fixed. Outcomes: detection (H) rate under P2P-only vs envelope; neutral edits labelled U; attribution precision.
- Decision rule: envelope adds value if detection rate under envelope − P2P-only > 0 with bootstrap CI excluding 0.

## RQ4 Cost
- Oracle executions, wall-clock, invalid (syntax-error) configurations per patch for: SHIFT (requires-closure + syntax pre-check + ddmin), plain ddmin, leave-one-out, exhaustive (patches with ≤ 8 units). Agreement of the minimal sets with exhaustive minimum where feasible.

## HPC usage policy
- GPU nodes only for LLM inference (Ollama, pinned models from the shared model cache). CPU-only Slurm allocations for analysis. Every stage is smoke-tested on each cluster (Fir H100, Rorqual H100, Narval A100) before the full run; throughput measured in smoke picks cluster shares.

## Amendments
- 2026-11-17 A1 (before any LLM measurement): LLM-judge models changed to the six models present in the pre-staged Ollama caches on Rorqual and Narval (compute nodes have no internet): qwen2.5-coder:7b, llama3.1:8b, gemma2:9b, phi4:14b, deepseek-coder-v2:16b, mistral-small:24b. gpt-oss:20b, devstral:24b and qwen3-coder:30b are not cached. num_ctx reduced to 8192 (prompt p95 ≈ 1.4k tokens; gemma2 limit 8192).
- 2026-11-17 A2: Fir excluded — login node denied access to /home and /scratch during the session window (infrastructure, not performance).
- 2026-11-17 A3: 10 Django/SymPy instances pinned to x86_64 by the harness are excluded (arm64 oracle).
- 2026-11-17 A4 (smoke-based, before any full LLM output was analysed): deepseek-coder-v2:16b excluded. In the smoke test its Ollama runtime processed prompts at ~73 tok/s on an H100 (CPU-level), produced 3/24 answers in 7 min, 0/3 parseable. Final LLM-judge panel: qwen2.5-coder:7b, llama3.1:8b, gemma2:9b, phi4:14b, mistral-small:24b. Allocation: Rorqual seeds 11,22; Narval seed 33 (fallback to Rorqual if Narval does not schedule).
- 2026-11-17 A5: Execution set = 295 validated instances (221 Django + 74 SymPy; 1 Django gold patch fails on arm64, 10 x86-only).
- 2026-11-17 A6 (method correction during execution, triggered by an internal consistency check on the first 214 records, before any RQ analysis was finalised): (i) a closure-aware reduction pass now follows ddmin, because units entering the ddmin result only through the requires-closure could be removable (1-minimality violated, e.g. django__django-11333); (ii) a fifth label C (coupled) is introduced for units whose single withdrawal invalidates the patch but which lie outside D* (removable as a group). "Needed" = N ∪ J throughout. (iii) Hunks are now located by exact pre-image match nearest to the declared line (as `git apply` does); 3 jobs had offset hunks. All 79 records that these changes could affect (non-empty requires relation, anomalies, offset hunks, errors) were deleted and re-run with the corrected code; unaffected records are identical under both versions.
- 2026-11-17 A7 (method correction during execution, found while preparing the running example): the requires relation now follows Python's per-module binding. Import aliases and assignment targets create requires edges only between units of the same file; new functions/classes may link units across files. Previously, two files that each added `from x import Name` were linked to each other, which made an unneeded import look necessary (django__django-13297, Kimi K2.5). All 24 records whose relation changed were deleted and re-run.
- 2026-11-17 A8 (exploratory, added after the main LLM-judge results were seen): "informed judge" variant. Same prompts plus the goal-test names and the instance's test patch (truncated to 4,000 characters); one seed (11); same five models and decoding. Purpose: test the objection that judges were disadvantaged by not seeing the tests. Reported as exploratory.
- 2026-11-17 A9 (efficiency only): the envelope's base-revision runs (twice) and reference-patch run are cached per (instance, selected test modules) and shared by all patches of the instance. The measurement is identical; reported envelope cost counts only executions actually performed. One-time container setup commands (locale generation) run once per container instead of before every test run.
- 2026-11-17 A10 (validity safeguard, decided after observing a "regression" of a reference patch against itself, i.e. a flaky envelope test): every envelope regression, in all records, is confirmed by an independent re-execution of the full patch in a fresh container; only reproducing regressions count, and harmful-unit attributions are re-checked (`experiments/confirm_regressions.py`). Unconfirmed regressions are reported as flaky.
- 2026-11-17 A11 (infrastructure bug fix): on a test-run timeout the oracle killed the launcher but not SymPy's interpreter child (`python -c ... runtests import _test`), leaving orphaned test processes that slowed later runs. All test processes in the container are now killed on timeout. No finished record contained a timed-out run; the 15 in-flight jobs were discarded and re-run.
- 2026-11-17 A12 (compute-driven, decided before any SymPy injection was executed): SymPy envelope runs that include catch-all test modules (e.g. sympy/core/tests/test_args.py) take up to 15 min each under load. The injection study keeps all 440 Django injections and restricts SymPy to a seeded random sample of 30 of the 71 SymPy instances with eligible injection sites (60 injections; seed 2026; list in results/processed/jobs/injection_sympy_sample.json). The full job list is preserved in injection_jobs_full.jsonl.
- 2026-11-19 A13 (v2 revision, reporting): decisions for H2 and H3 are reported explicitly (`analysis/revision/v2_checks.py`). H3's comparison "or SHIFT's" F1 is vacuous (SHIFT defines the labels); the best LLM judge is used. The RQ1 resolution model is one pooled GEE with system fixed effects instead of one GEE per system (several systems resolve few instances); deviation disclosed.
- 2026-11-19 A14 (v2 revision, post hoc): SHIFT-Intent frontend implemented (`src/shift/intent/`); contracts generated and compiled for all 295 instances, compared with the oracle's obligations, statically mutated, and validated against one fresh base execution per instance (`experiments/compile_contracts.py`).
- 2026-11-19 A15 (v2 revision, post hoc): diff-only reimplementation of TRIM's reverse-greedy hierarchical search (`trim_diff_only`), replayed on all multi-unit patches against recorded outcomes; unobserved configurations executed with the same oracle (`experiments/trim_baseline.py`). Not the authors' tool (no public artifact; no agent trajectories in replayable form).
- 2026-11-19 A16 (v2 revision, exploratory): the three pre-registered judges missing from the HPC caches (qwen3-coder:30b, gpt-oss:20b, devstral:24b) run on the local GB10 with the same prompts and decoding, one seed (11) (`experiments/run_local_judges.sh`).
- 2026-11-19 A17 (v2 revision, implementation): envelope add-back uses the transitive requires closure (as in Algorithm 3). For all 25 recorded regression records it coincides with the direct closure used during the campaign.
